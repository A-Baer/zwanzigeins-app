# Security Policy

## Reporting a vulnerability

Please report security vulnerabilities privately through GitHub's private
vulnerability reporting or a private security advisory for this repository.
Do not open a public issue for an undisclosed vulnerability.

Include the affected file or component, steps to reproduce the issue, and any
known impact. Please do not include passwords, tokens, personal data, or other
secrets in the report.

This project is maintained on a best-effort basis. The public repository does
not contain Apple signing credentials, provisioning profiles, API keys, or
other deployment secrets.
